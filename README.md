## 📖 About

**ATM System OOP** is a software project that models an Automated Teller Machine (ATM) using Object-Oriented Programming concepts.

The project is organized as a Visual Studio solution. Its goal is to provide a structured environment for understanding ATM-related application logic and object-oriented software organization.

## ✨ Project Highlights

- 🏧 ATM system simulation.
- 🧩 Object-oriented project structure.
- 🛠️ Visual Studio solution for development.
- 🖼️ A dedicated `Pics` folder for project images and visual resources.

> The exact operations and class responsibilities depend on the implementation in the source files.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/XP-IMAD/ATM-System-OOP.git
```

### 2. Open the solution

Open `ATM-System-OOP.slnx` with a compatible version of **Visual Studio**.

### 3. Build and run

- Allow Visual Studio to load the solution.
- Build the project.
- Set the startup project if needed.
- Run the application.

> Make sure the required development workload and SDK for the project are installed.
